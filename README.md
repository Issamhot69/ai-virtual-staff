# AI Virtual Staff

Application React (Vite) reproduisant la plateforme de création d'employés virtuels IA.

## Installation
    npm install

## Développement
    npm run dev

## Build production
    npm run build

## Structure
- src/App.jsx — routeur simple landing/wizard
- src/Landing.jsx — page de vente publique
- src/Wizard.jsx — wizard de création en 6 étapes
- diagram/schema-global.mmd — schéma Mermaid du fonctionnement global
- docs/architecture.md — documentation technique
